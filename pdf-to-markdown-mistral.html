PDF scan → Markdown

Dùng Mistral OCR API để trích xuất nội dung PDF scan sang Markdown, sẵn sàng nạp vào Chatbase.

Key chỉ được dùng trong trình duyệt của bạn để gọi trực tiếp API Mistral, không được lưu lại hay gửi đi đâu khác.
Kéo thả file PDF vào đây, hoặc bấm để chọn file
